AGENTCODI 0.6.11 corrects first-party Java terminal-output handling for Unicode characters outside the Basic Multilingual Plane. `TerminalOutputBuffer` previously processed a backspace character by removing a single UTF-16 code unit, which could leave an unpaired surrogate when the preceding character was represented by a surrogate pair. Backspace handling now removes the complete preceding Unicode code point while preserving the existing newline boundary and bounded terminal-output behavior. Focused Java regression coverage verifies supplementary Unicode handling and prevents malformed UTF-16 from being exposed through terminal snapshots. This change adds no provider client, network transport, executable dependency or third-party component.

AGENTCODI 0.6.10 adds a transient compatibility-approval control to the first-party Java execution-mode and session path. When enabled, Compatibility Mode sends the Codex app-server protocol value `approvalPolicy: "untrusted"` for `thread/start`, `thread/resume`, and `turn/start`, corresponding to the app-server's internal `UnlessTrusted` approval policy. Trusted read commands may continue automatically, while file changes and commands requiring approval use AGENTCODI's existing native approval dialogs. The setting defaults to disabled, is not persisted, and does not alter the `danger-full-access` permission contract or its existing execution behavior. The change consists only of first-party Java UI, state and RPC wiring with focused Java protocol/state and C++ framing coverage; it adds no provider client, network transport, executable dependency or third-party component.

AGENTCODI 0.6.9 Directory processing has been adjusted to ensure that excluded entries can still be correctly identified.If a directory itself is not to be exported, its contents are scanned solely to determine which entries are excluded; no files are opened or added to the archive during this process.The existing maximum directory depth and scan budget apply to this operation as well, keeping the traversal limited and predictable.

AGENTCODI 0.6.9 adds only first-party Java catalog-projection validation, focused tests and documentation to the 0.6.8 payload. An installed app identifier was previously carried through the same bounded display projection as titles and descriptions, which trims, redacts and shortens once the projection budget is spent. On a workspace with several hundred documented MCP tools the budget was exhausted before the app inventory was read, so an app was listed under a shortened identifier, app/read was addressed with an identifier the app-server never issued, and the app lost its name and tool list. Identity is now projected under a separate rule that never reshapes a value: an identifier the display rules would shorten or rewrite makes the entry unusable and it is dropped with the existing truncation disclosure. This release adds no provider client, network transport, executable dependency or third-party component.
