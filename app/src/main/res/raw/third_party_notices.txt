Node.js LTS 24.18.0 Android ARM64 toolchain

AGENTCODI packages a SHA-256-pinned Node.js LTS 24.18.0 executable and its
matching runtime libraries from verified Termux packages. Android executes
these files from the app's private native-library directory. The toolchain is
not downloaded at runtime; an explicit user action or a Codex command accepted
in the native approval dialog creates only a private activation marker below
workspace/toolchain.

The private native-library directory is not placed in command PATH. The actual
Node.js, Python, and ripgrep executable ELFs each require a bundled AGENTCODI
C++ policy guard before their own entry point. Those first-party Apache-2.0
guards enforce the same activation and environment policy for absolute ELF
invocations; the ripgrep guard also enforces its restricted arguments. A
relocation-free first-party entry attestor inside each executable opens the
genuine sibling guard without following links and verifies its device and inode
against the executable process mapping. A substituted policy library is
therefore rejected before the original program entry runs.

- Node.js 24.18.0: MIT License and the upstream third-party notices collected
  in the Node.js LICENSE file.
